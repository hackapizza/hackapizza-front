# 🍕 Sistema de Pedidos de Pizza - Migração PHP para React/NestJS

## Sobre o Projeto
Este projeto consiste na migração de um sistema de pedidos de pizza originalmente desenvolvido em PHP para uma arquitetura moderna. A solução oferece:

- interface web moderna, desenvolvida com Next.js 15, TypeScript e Tailwind CSS.

- experiência de usuário fluida e responsiva, integrada com a API REST do backend.

---

## Arquitetura

### Core
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS

### UI/UX
- Shadcn/ui para componentes base
- Lucide React para ícones
- Geist Font para tipografia

### Gerenciamento de Estado & Dados
- Context API para gerenciamento de estado
- Axios para requisições HTTP

---

## Funcionalidades Principais
- Autenticação de usuários
- Interface responsiva e moderna
- Formulários validados
- Integração com API REST

---

## Requisitos

Antes de começar, instale:

- [Node.js](https://nodejs.org)
- [NPM](https://www.npmjs.com/)

## Passo a passo para rodar o projeto

### 1. Clonar o repositório

```bash
git clone <URL-do-repositório>
cd <nome-do-projeto>
```

### 2. Instalar dependências

```bash
npm install
```

### 3. Iniciar o servidor de desenvolvimento

```bash
npm run dev
```

---

## 📌 Observações

- Por padrão o aplicativo estará disponível em http://localhost:3001

- Certifique-se que a API backend está rodando antes de iniciar o frontend
